# /情报源健康检查 — 检查源可用性、重复率和维护风险

## 参数解析

- `$源目录`：必填，可以是 `.claude/agent-memory/rss-archive-librarian/source-catalog.md` 中的一组源，或用户直接给出列表。
- `$检查范围`：可选，全部源 / 某主题包 / 某来源等级。
- `$修复建议`：可选，是否输出替代 route、selectors 或删除建议。

## 核心指令

### 1. 可用性检查

对每个源执行轻量验证：

- RSS / route：`rss-intelligence summary:true`。
- 普通列表页：`list-extract`。
- route 疑似失效：`route-discover` 重新检查。

### 2. 健康指标

记录：

| 指标 | 说明 |
|---|---|
| 状态 | success / empty / failed / login-required |
| 条目数 | 本次扫描返回数量 |
| 最近时间 | 最新条目发布时间 |
| 重复风险 | 与其他源标题或链接重复 |
| 维护风险 | route 过期、selector 失效、登录态依赖 |

### 3. 修复建议

- 失效 route：重新 route-discover。
- 空结果源：降低扫描频率或标记待观察。
- 重复源：保留可靠度更高的一手源。
- 需要 selectors：建议交给 `/网页变更预警`。

## 输出格式

### 源健康总览

| 来源 | 等级 | 状态 | 条目数 | 最新时间 | 风险 | 建议 |
|---|---|---:|---:|---|---|---|

### 需要维护的源

- 失效源。
- 空结果源。
- 高重复源。
- 登录态或 selectors 风险源。

### memory 更新建议

列出建议写回 `source-catalog.md` 的健康备注。
