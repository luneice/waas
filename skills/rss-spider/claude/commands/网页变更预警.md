# /网页变更预警 — 为无 RSS 页面设计监控规则

## 参数解析

- `$URL或监控对象`：必填，网页 URL、政策页、价格页、公告页、招聘页等。
- `$关键词`：可选，触发词。
- `$selector`：可选，CSS 选择器。
- `$触发条件`：可选，出现/消失/数量变化/价格变化/标题新增。
- `$频率`：可选，默认 daily。

## 核心指令

### 1. 能力探测

按顺序尝试：

1. `route-discover` 判断是否已有 RSSHub route。
2. route 可用则 `rss-intelligence summary:true`。
3. route 不可用则 `list-extract`。
4. 单页详情或页面主体则 `page-extract`。

### 2. 规则设计

生成 WatchRule，但要明确当前 Claude 层不等于后台调度器。

### 3. 预警分级

| 级别 | 条件 |
|---|---|
| P0 | A 级来源出现正式发布、处罚、暂停、价格大幅变化 |
| P1 | A/B 级来源出现征求意见、试点、产品更新 |
| P2 | C/D 级来源出现讨论升温或标题变化 |

### 4. 通知内容

预警通知必须包含：标题、来源、时间、链接、触发条件、证据片段。
