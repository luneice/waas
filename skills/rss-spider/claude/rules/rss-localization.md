# rss-spider · 本土化规则

## 1. 时间和语言

- 默认语言：简体中文。
- 默认时区：`Asia/Shanghai`。
- 日报默认按北京时间自然日统计。
- 国际源保留原文标题时，需要给中文摘要。

## 2. 中文实体归一化

同一实体可能有多种写法，分析前尽量归一：

| 类型 | 示例 |
|---|---|
| 公司 | 阿里巴巴 / Alibaba / BABA / 9988.HK |
| 机构 | 工信部 / MIIT / 工业和信息化部 |
| 产品 | 通义千问 / Qwen / Qwen3 |
| 地区 | 中国大陆 / 内地 / mainland China |

长期复用的别名交 `rss-archive-librarian` 写入 `.claude/agent-memory/rss-archive-librarian/entity-aliases.md`。

## 3. 主题包默认分类

建议优先支持这些主题包：

- 政策监管：部委、地方、交易所、监管处罚、标准征求意见。
- AI/开源技术：模型、框架、云厂商、开发者生态、论文/榜单。
- 公司竞品：公司公告、产品更新、融资、招聘、价格、生态合作。
- 金融公告：上市公司公告、宏观数据、利率、外汇、期货、研究报告。
- 舆情热点：微博、B 站、知乎、论坛、搜索结果，只作为待核验信号。

## 4. 风险表达

- 政策类不要夸大影响，区分“征求意见”“试点”“正式发布”。
- 金融类不要给投资建议，只做事实梳理和风险提示。
- 舆情类必须标注样本偏差和待核验。
- 登录态内容不要输出原始全文或敏感账号信息。
