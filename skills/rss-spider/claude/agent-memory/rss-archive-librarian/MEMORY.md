# rss-archive-librarian Memory 索引

> 档案馆员 Agent 的持久记忆（`memory: project`），是整个情报中心的**共享档案**：其他 Agent / 斜杠命令按以下路径直接读取，写入统一由档案馆员维护（单一写者）。

- `source-catalog.md`：**已验证建档**的情报源（一源一节，含访问方式 / 可靠度 / 健康状态 + 日期）。
- `topic-profiles.md`：**用户实际建立**的主题包（主题 → 绑定的 sourceId + 关键词 + 实体 + 节奏）。
- `entity-aliases.md`：**实际确认过**的实体别名映射（标准名 → 别名，一行一条）。
- `user-preferences.md`：**用户明确表达**的长期偏好（每条带确认日期）。
